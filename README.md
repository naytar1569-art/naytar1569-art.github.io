# ระบบนับสต็อกร้าน (LamthongBBQ)

เว็บแอปนี้ออกแบบสำหรับการใช้งานบนมือถือ โดยมีฟีเจอร์หลัก:

- แบ่งสต็อกเป็นหมวดหมู่ได้
- เพิ่ม/ลบรายการในแต่ละหมวดหมู่
- ระบุชื่อรายการ, จำนวน, และหน่วยได้
- รองรับการใช้งานบนมือถือด้วยหน้าจอสัมผัส
- เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์

## วิธีใช้งานบน GitHub Pages

1. สร้าง GitHub repository ชื่อ `lamthongbbq.github.io`
2. วางไฟล์ทั้งหมดจากโฟลเดอร์นี้ไว้ที่รากโปรเจค (root)
3. เปิด terminal ที่โฟลเดอร์นี้ แล้วรันคำสั่งต่อไปนี้

```bash
deploy-github-pages.cmd <username>
```

4. เข้าใช้งานที่ `https://lamthongbbq.github.io`

> ถ้ายังไม่สะดวกตั้งชื่อ repo เป็นชื่อโดเมน ให้ใช้วิธีโฮสต์เป็น project page แล้วเรียกผ่าน `https://<username>.github.io/<repo>` แทนได้
