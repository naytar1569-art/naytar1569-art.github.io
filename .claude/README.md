# ระบบนับสต็อกร้าน (มือถือ)

เว็บแอปนี้ออกแบบสำหรับการใช้งานบนมือถือ โดยมีฟีเจอร์หลัก:

- แบ่งสต็อกเป็นหมวดหมู่ได้
- เพิ่ม/ลบรายการในแต่ละหมวดหมู่
- ระบุชื่อรายการ, จำนวน, และหน่วยได้
- รองรับการใช้งานบนมือถือด้วยหน้าจอสัมผัส
- เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์มือถือหรืออุปกรณ์ของคุณ
2. กดปุ่ม `สร้างหมวดหมู่ใหม่` เพื่อเพิ่มหมวดหมู่
3. กด `+ รายการ` ในแต่ละหมวดเพื่อเพิ่มสินค้าหรือวัตถุดิบ
4. ใช้ปุ่ม `+ เพิ่ม`, `- ลด`, `แก้ไข`, และ `ลบ` เพื่อจัดการสินค้า

## โดเมนฟรีที่แนะนำ

หากต้องการนำเว็บไปใช้งานออนไลน์แนะนำบริการโฮสต์ฟรีที่ใช้งานได้ยาวนาน:

- `lamthongbbq.github.io` (GitHub Pages)
- `lamthongbbq.netlify.app` (Netlify)
- `lamthongbbq.pages.dev` (Cloudflare Pages)

> คำแนะนำ: ใช้ชื่อโดเมนเริ่มด้วย `lamthongbbq` ตามที่ต้องการ และเลือกโฮสติ้งฟรีที่เชื่อถือได้ เช่น GitHub Pages หรือ Netlify เพื่อใช้งานได้ยาวนาน

## ไฟล์สำคัญ

- `index.html` : หน้าเว็บหลัก
- `style.css` : สไตล์สำหรับมือถือและเดสก์ท็อป
- `script.js` : ตรรกะจัดการสินค้าร้าน
- `manifest.webmanifest` : ตั้งค่า PWA เบื้องต้น
